# ALMAAT — Content Index

![Content Index](/images/_index.svg)

Master index of the ALMAAT framework. The book builds one ontology from a single
primitive (the `Azon`) up to `Agent` and `Growth`, then applies it to the human, the
collective, and software engineering. Sections are ordered by ontological layer.

- [Welcome](welcome.md) — what ALMAAT is and how the layers stack.
- [Quotes](_quotes.md) — curated quotations.
- [Term Translations](_translations.md) — canonical English Terms to Belarusian-rooted equivalents.
