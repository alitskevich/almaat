# Welcome to ALMA

ALMA is a general-purpose universal cognitive framework for cognitive modeling.

It builds a layered ontology from a single irreducible primitive (the `Azon`) through increasingly rich structures: `Set`, `Graph`, `Language`, `Sequence`, `Space`, dynamic `System`, `Mind`, `Agent`, and `Growth`.

#### Chapters

The chapters are layered — each presupposes the previous. The minimum core for cognitive modeling is `00` → `06` → `05`, returning to `01`, `02`, `03`, `04` as needed for the underlying mathematical primitives. The cognitive-modeling chapters (`07`, `09`, `10`) then build on those.

#### Notes

The framework uses **English Terms as canonical** throughout the content. Each Term backed by a Belarusian root is recorded in [translations](_translations.md) — that file is the offload point for readers integrating with mainstream literature.
